# User data stays on their device

Everything a user enters (salary, commitments, savings, investments) is kept only in their own browser's local storage; the app has no accounts and no server that stores it. This avoids holding sensitive financial data at all, which removes breach risk and most of the obligations a stored dataset brings under Malaysia's Personal Data Protection Act (breach reporting within 72 hours, a data protection officer once financial data covers more than 10,000 users). The trade-off is accepted: no syncing between devices, data is lost if the user clears their browser, and features that need a server (shared links that carry personal figures, accounts) aren't possible.

## Consequences

- Any future feature that sends a user's figures off the device (analytics with figures, AI calls, error reports with inputs) needs a new decision first.
- Whether the PDPA applies at all to purely on-device data should still be confirmed by a lawyer.
